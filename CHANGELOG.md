### Fixed

- **Xtream catalog after app restart (Android TV / Shield)** — Large cached catalogs were stored as **multi‑MB JSON in SQLite `TEXT` columns**, which **cannot be read back** on Android (**`CursorWindow`** **~2 MB** per row → **`Row too big to fit into CursorWindow`**, empty Live TV). **`XtreamCatalogCacheDb`** now keeps **metadata in SQLite** and writes **`iptvil_cat_full_*.json`** / **`iptvil_cat_live_*.json`** under the app databases path; DB **v5** clears legacy blob columns. See **`documentation/04-data-playlists-and-xtream.md`**.

- **Movies / Series — two-step back from player** — Stopping playback no longer pops **both** the player and the **details** route in one gesture (duplicate back suppression + sync **`onPlayerClosed`**).
- **Browse sync after VOD** — **`_syncMovieBrowseToId` / `_syncSeriesBrowseToId`** no longer **`requestFocus`** on poster rails while details is still visible (prevents focus jumping to browse under the details route).
- **Live TV channel tiles** — Focus ring without scale-up past the cell; **`ClipRRect`** + **`BoxFit.contain`** for logo+text cards to reduce side clipping.

- **Preview audio after app exit / background** — Native hero preview is released on **`Activity.onPause`** and when exiting from shell; **`HeroLivePreview`** recreates the texture after resume when needed.
- **Clock weekday casing** — Framed **`MON`–`SUN`** no longer render as lowercase when segment font is enabled (split **Text.rich** + **Roboto** for letters).
- **Movies / Series / Live TV rails** — Focus rings on posters and tiles clip less (scroll **`clipBehavior`**, removed full-column **`ClipRect`** on Movies/Series).
- **Build (older Flutter)** — **`Row`** has no **`clipBehavior`** on some SDKs; poster rows omit that parameter (category **`ListView`** still uses **`clipBehavior`** where valid).
- **Clock appearance** — Default unframed time uses no text shadows and explicit `TextDecoration.none` to avoid stray underline-like artifacts on some displays.
- **Settings route** — `ClockSettingsScreen` requires `import 'clock_settings_screen.dart'`; route builder uses non-const construction where the analyzer rejects `const` in that context.
- **VOD fullscreen stretch (e.g. Shield)** — **Movies / episodes** no longer distort: Flutter **contain**-sized **`Texture`** from native **display** dimensions + **`SCALE_TO_FIT`** (see **`documentation/06-playback-and-native-player.md`**).
- **Add Playlist / TV keyboard crash (ONN, Chromecast with Google TV, similar devices)** — Root **`android/build.gradle`** forced **`androidx.core:core`** / **`core-ktx`** to **1.12.0**, which is **older** than the AndroidX API Flutter’s **`TextInputPlugin`** calls (**`EditorInfoCompat.setStylusHandwritingEnabled`**). Focusing a **`TextField`** then crashed with **`java.lang.NoSuchMethodError`**. Resolution strategy now forces **`core` / `core-ktx` 1.15.0** (see **`documentation/07-android-build-and-branding.md`**). **NVIDIA Shield** and other devices continue to run the same APK; the change aligns packaged AndroidX with the Flutter engine.
- **Android video black screen (audio only) on some updated TVs / Shields (Impeller + Vulkan)** — Native playback no longer uses legacy **`createSurfaceTexture()`**. **`NativeExoPlayerSession`** and **`NativeLivePreviewSession`** use **`TextureRegistry.createSurfaceProducer()`**, **`SurfaceProducer.Callback`** (background / resume), **`setSize`** when dimensions are known, and re-attach **`ExoPlayer`** to **`getSurface()`** after resize—aligned with Flutter’s **Android surface plugins** guidance. Same APK path for **Shield, ONN, Chromecast**, and other Android TV devices; requires a **Flutter SDK** that includes **`createSurfaceProducer`** (current stable toolchains).
- **Android video wrong colors (neon / solarized; UI fine) on some TVs — Impeller Vulkan** — With **`SurfaceProducer`** + **Impeller (Vulkan)**, hardware-decoded frames can be **mis-sampled** on certain SoCs. **`AndroidManifest.xml`** sets **`io.flutter.embedding.android.EnableImpeller`** to **`false`** under **`<application>`** (not **`activity`** — otherwise the flag is **ignored**, [flutter/flutter#154252](https://github.com/flutter/flutter/issues/154252)) so Flutter uses **Skia + OpenGL**; **native code still uses `SurfaceProducer`**. After **`flutter upgrade`**, you may try **`true`** again and re-test.
